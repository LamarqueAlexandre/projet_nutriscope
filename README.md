# NutriScope - Application de scan produits

> NutriScope est une application qui permet de scanner un produit et d'obtenir son nutriscore

## Contexte

> Cette application est le projet fil rouge de la certification "Développeur - Intelligence Artificielle", proposée par M2I formation et LAHO.

## Fonctionnalités

* Scan de produit
* Prédiction du NutriScore
* Assistant conversationnel
* Moteur de substitution produit

## Stack technique

* Python 3.12
* Pandas
* Scikit-learn
* PostgreSQL

Voir [pyproject.toml](./pyproject.toml) pour la liste complète des dépendances.
